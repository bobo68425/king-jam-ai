# King Jam AI 部署線上 (Vercel & Railway)

本專案目前已由 Cloud Run 遷移至 **Vercel** (前端) 與 **Railway** (後端)。

## 方式一：GitHub Actions 與自動部署

程式推送到 `main` 分支後，會自動觸發以下行為：

- **前端**：Vercel 會偵測 GitHub 異動並自動重新部署。
- **後端**：Railway（若已連結 GitHub）會偵測 `main` 分支異動並自動編譯 Dockerfile 部署。

### 步驟

1. **提交並推送到 main**
   ```bash
   git add .
   git commit -m "描述您的變更"
   git push origin main
   ```

2. **檢查部署狀態**
   - 前端：[Vercel Dashboard](https://vercel.com/dashboard)
   - 後端：[Railway Dashboard](https://railway.app/dashboard)

## 方式二：資料庫遷移 (GitHub Actions)

如果您的變更涉及資料庫結構修改：

1. 到 GitHub Actions 頁面。
2. 選擇 **「Database Migration」**。
3. 點擊 **Run workflow**，環境選擇 **production**，動作選 **upgrade**。

## 部署後檢查

- **前端**：https://kingjam.app
- **後端健康檢查**：https://api.kingjam.app/health (應回傳 `{"status": "ok"}`)
