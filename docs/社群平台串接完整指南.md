## 🟢 簡單平台 (推薦優先串接)

### 1. WordPress (⭐ 最簡單)

**優點**:
- ✅ 無需申請 OAuth 應用程式
- ✅ 使用應用程式密碼即可
- ✅ 立即可用,無審核流程
- ✅ 適合部落客和內容創作者

**串接步驟**:
```
1. 登入 WordPress 網站後台
2. 前往「使用者」→「個人資料」
3. 向下捲動到「應用程式密碼」
4. 輸入名稱 (如 "King Jam AI")
5. 點擊「新增應用程式密碼」
6. 複製產生的密碼 (格式: xxxx xxxx xxxx xxxx)
7. 在 King Jam AI 中輸入:
   - WordPress 網站 URL
   - 使用者名稱
   - 應用程式密碼
```

**注意事項**:
- 應用程式密碼保留空格
- 需要 WordPress 5.6 以上版本
- 需啟用 REST API (預設已啟用)

**實作狀態**: ✅ 完整實作
- 檔案: `backend/app/services/social_platforms/wordpress.py`
- 支援文章發布、媒體上傳、分類管理

### 2. YouTube (⭐⭐ 簡單)

**優點**:
- ✅ 使用 Google OAuth,申請簡單
- ✅ 無需應用程式審核
- ✅ 與 Google 帳號共用憑證
- ✅ 即時生效

**串接步驟**:
```
1. 前往 Google Cloud Console
   https://console.cloud.google.com/

2. 建立專案或選擇現有專案

3. 啟用 YouTube Data API v3
   - 前往「API 和服務」→「程式庫」
   - 搜尋 "YouTube Data API v3"
   - 點擊「啟用」

4. 建立 OAuth 2.0 憑證
   - 前往「憑證」→「建立憑證」→「OAuth 2.0 用戶端 ID」
   - 應用程式類型: 網頁應用程式
   - 授權的重新導向 URI:
     * http://localhost:8000/oauth/youtube/callback (開發)
     * https://api.kingjam.app/oauth/youtube/callback (生產)

5. 取得憑證
   - 用戶端 ID → GOOGLE_CLIENT_ID
   - 用戶端密鑰 → GOOGLE_CLIENT_SECRET
```

**環境變數**:
```bash
GOOGLE_CLIENT_ID=your_client_id.apps.googleusercontent.com
GOOGLE_CLIENT_SECRET=GOCSPX-xxxxx
YOUTUBE_REDIRECT_URI=http://localhost:8000/oauth/youtube/callback
```

**配額限制**:
- 每日配額: 10,000 單位 (免費)
- 上傳影片: 1,600 單位/次
- 建議: 申請配額增加 (需填寫表單)

**實作狀態**: ✅ 完整實作
- 檔案: `backend/app/services/social_platforms/youtube.py`
- 支援影片上傳、播放清單管理

**方案 A: Instagram Login (推薦,較簡單)**

**優點**:
- ✅ 不需要 Facebook 粉絲專頁
- ✅ 個人帳號即可使用
- ✅ 審核較簡單

```

   - 不是 "Instagram Basic Display"
   - 不是 "Instagram Graph API"

4. 設定 Instagram Login
   - Valid OAuth Redirect URIs:
     * http://localhost:8000/oauth/meta/callback
     * https://api.kingjam.app/oauth/meta/callback
   - Deauthorize Callback URL:
     * https://api.kingjam.app/oauth/meta/deauthorize
   - Data Deletion Request URL:
     * https://api.kingjam.app/oauth/meta/delete

5. 取得憑證
   - App ID → INSTAGRAM_APP_ID
   - App Secret → INSTAGRAM_APP_SECRET
```

**環境變數**:
```bash
INSTAGRAM_APP_ID=xxxxx
INSTAGRAM_APP_SECRET=xxxxx
```

### 7. Threads (⭐⭐⭐⭐ 複雜)

**重要**: Threads 需要**獨立的** App ID,不能使用 Facebook/Instagram 的!

**步驟**:
```
1. 前往 Meta for Developers
   https://developers.facebook.com/

2. 建立新應用程式 (或使用現有)

3. 新增 Use Case: "Access the Threads API"
   - 在應用程式設定中找到 "Use cases"
   - 點擊 "Add" → 選擇 "Access the Threads API"

4. 在 Threads API Settings 中取得憑證
   - Threads app ID (與 Facebook App ID 不同!)
   - Threads app secret
   - 這些是專門給 Threads 使用的

5. 設定 OAuth Redirect URIs
   - http://localhost:8000/oauth/meta/callback
   - https://api.kingjam.app/oauth/meta/callback

6. 申請權限
   - threads_basic
   - threads_content_publish
   - threads_manage_insights
   - threads_manage_replies
   - threads_read_replies
```

**環境變數** (重要!):
```bash
# Threads 專用憑證 (必須設定)
THREADS_APP_ID=xxxxx  # 不是 FACEBOOK_APP_ID!
THREADS_APP_SECRET=xxxxx

# 或使用通用 Meta 憑證 (若 Threads 未設定則 fallback)
META_APP_ID=xxxxx
META_APP_SECRET=xxxxx
```

**常見錯誤**:
```
❌ 使用 FACEBOOK_APP_ID 發布到 Threads
   → 錯誤: "Invalid OAuth access token"

✅ 使用 THREADS_APP_ID 發布到 Threads
   → 成功!
```

**實作狀態**: ✅ 完整實作
- 檔案: `backend/app/services/social_platforms/meta.py`
- 支援文字、圖片、影片發布

**替代方案 B: 第三方排程工具整合**

**推薦工具**:
1. **Later** (https://later.com/)
   - 支援 TikTok 排程
   - 提供 API 整合
   - 月費: $25-80

2. **Hootsuite** (https://hootsuite.com/)
   - 企業級社群管理
   - 支援多平台
   - 月費: $99+

3. **Buffer** (https://buffer.com/)
   - 簡單易用
   - 支援 TikTok
   - 月費: $15-99

**整合方式**:
```python
# 使用第三方工具的 API
import requests

def schedule_tiktok_via_later(video_url, caption):
    """透過 Later API 排程 TikTok 影片"""
    api_key = os.getenv("LATER_API_KEY")
    
    response = requests.post(
        "https://api.later.com/v1/posts",
        headers={"Authorization": f"Bearer {api_key}"},
        json={
            "platform": "tiktok",
            "media_url": video_url,
            "caption": caption,
            "scheduled_at": "2026-02-16T10:00:00Z"
        }
    )
    
    return response.json()
```

## 💡 常見問題解決

### Q1: Instagram 授權後顯示 "需要 META_CONFIG_ID"
**原因**: 使用 Facebook Login 模式但未設定 Configuration ID

**解決方案**:
```bash
# 方案 A: 改用 Instagram Login (推薦)
INSTAGRAM_APP_ID=xxxxx
INSTAGRAM_APP_SECRET=xxxxx

# 方案 B: 設定 META_CONFIG_ID
META_CONFIG_ID=xxxxx  # 從 Meta 後台取得
```

---

### Q2: Threads 發布失敗 "Invalid OAuth token"
**原因**: 使用了 Facebook App ID 而非 Threads App ID

**解決方案**:
```bash
# 必須使用 Threads 專用憑證
THREADS_APP_ID=xxxxx  # 不是 FACEBOOK_APP_ID!
THREADS_APP_SECRET=xxxxx
```

---

### Q3: TikTok 審核被拒絕
**原因**: 
- 商業用途說明不清楚
- 缺少必要文件
- 應用程式類型不符

**解決方案**:
1. 詳細說明商業用途
2. 提供公司登記證明
3. 錄製清晰的使用流程影片
4. 考慮使用替代方案 (第三方工具)

---

### Q4: YouTube 配額不足
**原因**: 免費配額只有 10,000 單位/天

**解決方案**:
```
1. 申請配額增加
   - 前往 Google Cloud Console
   - API 和服務 → 配額
   - 申請增加 YouTube Data API v3 配額

2. 優化 API 使用
   - 快取頻道資訊
   - 批次處理請求
   - 使用部分回應 (fields 參數)

3. 付費方案
   - 聯絡 Google 銷售團隊
   - 企業級配額
```
