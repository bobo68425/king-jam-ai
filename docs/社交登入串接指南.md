# 社交登入串接指南

本指南說明如何完成 Google、Facebook、LINE 登入的線上環境串接。

---

## 一、現況說明

| 項目 | 狀態 | 說明 |
|------|------|------|
| 前端按鈕 | ✅ | 登入頁已有 Google、Facebook 按鈕 |
| 後端 API | ✅ | `/auth/google`、`/auth/facebook`、`/auth/line` 已實作 |
| Callback 頁面 | ✅ | `/auth/callback/google`、`/auth/callback/facebook` |
| **環境變數** | ❌ | 尚未加入部署流程 |
| **OAuth 後台設定** | ⚠️ | 需在 Google/Facebook 後台設定 Redirect URI |

---

## 二、前置準備

### 2.1 Google OAuth

1. 前往 [Google Cloud Console](https://console.cloud.google.com/apis/credentials)
2. 選擇專案（或建立新專案）
3. 「API 和服務」→「憑證」→「建立憑證」→「OAuth 2.0 用戶端 ID」
4. 應用程式類型：**網頁應用程式**
5. 授權的 JavaScript 來源：
   - `https://kingjam.app`
   - `https://www.kingjam.app`
6. 授權的重新導向 URI：
   - `https://kingjam.app/auth/callback/google`
7. 取得：
   - **用戶端 ID** → `GOOGLE_CLIENT_ID`
   - **用戶端密鑰** → `GOOGLE_CLIENT_SECRET`

### 2.2 Facebook OAuth

1. 前往 [Facebook Developers](https://developers.facebook.com/)
2. 建立應用程式或選擇現有應用程式
3. 新增產品：**Facebook 登入** → **網頁**
4. 在「Facebook 登入」→「設定」中：
   - 有效的 OAuth 重新導向 URI：`https://kingjam.app/auth/callback/facebook`
5. 取得：
   - **應用程式編號** → `FACEBOOK_APP_ID`
   - **應用程式密鑰** → `FACEBOOK_APP_SECRET`
6. 應用程式模式：**上線**（測試模式僅限測試用戶）

### 2.3 LINE Login（可選）

1. 前往 [LINE Developers](https://developers.line.biz/)
2. 建立 **LINE Login** Channel
3. Callback URL：`https://kingjam.app/auth/callback/line`
4. 取得 Channel ID 與 Channel Secret

---

## 三、GitHub Secrets 設定

在 GitHub 專案 → Settings → Secrets and variables → Actions 中新增：

| Secret 名稱 | 說明 | 範例 |
|-------------|------|------|
| `GOOGLE_CLIENT_ID` | Google OAuth 用戶端 ID | `xxx.apps.googleusercontent.com` |
| `GOOGLE_CLIENT_SECRET` | Google OAuth 用戶端密鑰 | `GOCSPX-xxx` |
| `FACEBOOK_APP_ID` | Facebook 應用程式編號 | 數字 |
| `FACEBOOK_APP_SECRET` | Facebook 應用程式密鑰 | 字串 |

---

## 四、部署流程（已更新）

完成上述設定後，Workflow 會自動傳遞環境變數：

- **前端**：建置時注入 `NEXT_PUBLIC_GOOGLE_CLIENT_ID`、`NEXT_PUBLIC_FACEBOOK_APP_ID`（需在 GitHub Secrets 設定）
- **後端**：Cloud Run 執行時注入 `GOOGLE_CLIENT_ID`、`GOOGLE_CLIENT_SECRET`、`FACEBOOK_APP_ID`、`FACEBOOK_APP_SECRET`

> ⚠️ **若尚未設定 Secrets**：部署仍會成功，但社交登入按鈕會顯示「尚未配置」或授權後失敗。設定 Secrets 後需重新部署前端與後端。

---

## 五、LINE 登入（可選）

若需 LINE 登入：

1. 建立 `frontend/app/auth/callback/line/page.tsx`（參考 Google callback）
2. 登入頁加入 LINE 按鈕
3. 後端 `/auth/line` 已存在，需確保 `LINE_CHANNEL_ID`、`LINE_CHANNEL_SECRET` 已設定

---

## 六、驗證步驟

1. 確認 GitHub Secrets 已設定
2. 觸發前端與後端部署（或 push 觸發）
3. 前往 https://kingjam.app/login
4. 點擊「使用 Google 登入」→ 應跳轉至 Google 授權頁
5. 授權後應導回並登入成功

---

## 七、常見問題

**Q: 點擊按鈕顯示「Google 登入尚未配置」？**  
A: 表示 `NEXT_PUBLIC_GOOGLE_CLIENT_ID` 在建置時為空，請確認 GitHub Secret 已設定且前端有重新部署。

**Q: 授權後顯示「Invalid Google code」？**  
A: 後端 `GOOGLE_CLIENT_ID`、`GOOGLE_CLIENT_SECRET` 可能未正確設定，或 Redirect URI 與 Google 後台不一致。

**Q: redirect_uri_mismatch？**  
A: 在 Google/Facebook 後台新增的「授權的重新導向 URI」必須與實際使用完全一致（含 https、無尾端斜線）。
