# 詐騙偵測運作檢查報告

**檢查日期**：2026-02-11

---

## 一、系統架構概覽

詐騙偵測服務 (`fraud_detection.py`) 主要功能：

| 功能 | 說明 |
|------|------|
| IP 地址追蹤 | 記錄 `ip_address_logs` |
| 裝置指紋追蹤 | 記錄 `device_fingerprints` |
| 風險評分 | 同 IP/裝置多帳號、同 IP 互相推薦 |
| 自動標記 | `UserRiskProfile`（referral_bonus_blocked 等） |
| 獎金暫停 | 高風險時不發放推薦獎金 |

**偵測策略**：同裝置多帳號、同 IP 多帳號、同 IP/裝置互相推薦、推薦環、VPN/Proxy

## 三、資料流程

```
登入 (email/密碼 或 社交)
    → record_login(user_id, ip, fingerprint?)
    → _record_ip → ip_address_logs
    → _record_fingerprint (若有) → device_fingerprints
    → _assess_risk → 同 IP/裝置檢查
    → _update_risk_profile → UserRiskProfile

推薦獎金發放前
    → check_referral_eligibility(user_id)
    → 若 referral_bonus_blocked 或 risk_level 高 → 拒絕發放
```
