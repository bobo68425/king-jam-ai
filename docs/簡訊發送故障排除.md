# 簡訊發送故障排除

## 一、Twilio 環境變數檢查

部署時需在 GitHub Secrets 設定的 Twilio 變數：

| Secret | 說明 | 必填 |
|--------|------|------|
| `TWILIO_ACCOUNT_SID` | 帳戶 SID (ACxxxx) | ✅ |
| `TWILIO_AUTH_TOKEN` | 主帳戶 Auth Token | ✅（二選一） |
| `TWILIO_API_KEY_SID` | API Key SID (SKxxxx) | ✅（二選一） |
| `TWILIO_API_KEY_SECRET` | API Key Secret | ✅（二選一） |
| `TWILIO_FROM_NUMBER` | 發送號碼 | ✅ |

**認證方式**：擇一即可  
- **Auth Token**：從 Twilio Console → Account → Auth Token 取得  
- **API Key**：從 Twilio Console → Account → API Keys 建立  

> 若使用 Auth Token，必須設定 `TWILIO_AUTH_TOKEN`；若使用 API Key，則設定 `TWILIO_API_KEY_SID` 與 `TWILIO_API_KEY_SECRET`。

---

## 二、Twilio Trial 帳號限制

**Trial 帳號**僅能：

1. **發送號碼**：必須使用 Twilio 提供的 Trial 號碼或 Sandbox 號碼  
   - 錯誤 21607：`The 'from' phone number must be the sandbox phone number for trial accounts`  
   - 解法：將 `TWILIO_FROM_NUMBER` 設為 Twilio Console 顯示的 Trial 號碼（如 +15005550006）

2. **收件號碼**：僅能發送至已驗證的手機號碼  
   - 需在 Twilio Console → Phone Numbers → Verified Caller IDs 新增要測試的號碼  
   - 台灣號碼格式：+886912345678

3. **升級帳號**：正式上線需升級為付費帳號，才能使用自己的發送號碼並發送至任意號碼。

## 三、常見錯誤與解法

| 錯誤訊息 | 可能原因 | 解法 |
|----------|----------|------|
| `Twilio Account SID 未設定` | 環境變數未傳入 | 檢查 GitHub Secrets 是否設定 `TWILIO_ACCOUNT_SID` |
| `Twilio 發送號碼未設定` | 環境變數未傳入 | 設定 `TWILIO_FROM_NUMBER`（E.164 格式，如 +14155551234） |
| `Twilio 認證資訊未設定` | 未設定 Auth Token 或 API Key | 擇一設定 `TWILIO_AUTH_TOKEN` 或 `TWILIO_API_KEY_SID` + `TWILIO_API_KEY_SECRET` |
| `[21607] The 'from' phone number...` | Trial 帳號使用自訂號碼 | 改用 Trial 號碼，或升級帳號 |
| `[21211] Invalid 'To' Phone Number` | 收件號碼格式錯誤 | 系統會自動轉為 +886912345678，確認前端傳入正確格式 |
| `[20003] Authentication Error` | SID 或 Token 錯誤 | 檢查 Twilio Console 的 Account SID、Auth Token 是否正確 |
| `[21608] The 'To' number is not a valid...` | Trial 帳號傳給未驗證號碼 | 在 Twilio Console 驗證該收件號碼 |

## 四、驗證流程

1. **檢查前端錯誤**：發送失敗時，畫面會顯示「發送失敗：{Twilio 錯誤}」  
2. **檢查後端日誌**：於 API 託管（如 Railway）Deploy Logs 搜尋 `[SMS]` 查看完整錯誤  
3. **檢查 Twilio 日誌**：Twilio Console → Monitor → Logs → Messaging，查看 API 請求與回應  

> 若畫面仍顯示「發送失敗，請稍後再試」（無具體錯誤），請檢查後端日誌取得 Twilio 回傳的錯誤代碼。

## 五、發送號碼格式 (E.164)

- 台灣：`+886912345678`（9 開頭，共 9 碼）
- 美國：`+14155551234`  
- `TWILIO_FROM_NUMBER` 必須為 E.164 格式，且為 Twilio 已購買／Trial 的號碼
